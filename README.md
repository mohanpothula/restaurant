# Imperial Pavilion 帝苑 — Fine Chinese Restaurant Website

A single-page restaurant website for **Imperial Pavilion 帝苑**, a fictional upscale Chinese fine-dining restaurant set in Singapore. Pure vanilla HTML/CSS/JS — no build tools, no frameworks, no dependencies.

**Live demo:** https://mohanpothula.github.io/restaurant/

## Features

- **Sticky navigation** — transparent on load, solid crimson on scroll; underline hover effect
- **Mobile hamburger menu** — full-screen overlay, closes on link click or Escape key
- **Hero section** — parallax background, animated fade-in content, scroll hint arrow
- **Menu grid** — three courses (Starters, Main Course, Desserts) with dish cards, image zoom on hover, shimmer accent bar
- **Testimonials carousel** — auto-advance every 4.5 s, dot nav, prev/next arrows, touch/swipe support, pauses on hover/focus
- **Reservation form** — full client-side validation (name, email, phone, guests 1–20, date ≥ today, time slot), accessible error messages, success confirmation
- **Contact Us section** — address, phone, email, opening hours, and an embedded Google Maps iframe for 8 Ann Siang Hill, Singapore
- **Scroll fade-in animations** — `IntersectionObserver`-powered, with stagger on dish cards
- **Accessible markup** — ARIA labels, roles, live regions, `sr-only` utility, `focus-visible` outlines throughout

## Tech stack

| Layer | Choice |
|---|---|
| Markup | Semantic HTML5 |
| Style | CSS3 with custom properties (design tokens in `:root`) |
| Behaviour | Vanilla ES5 JS wrapped in a single IIFE |
| Fonts | Google Fonts — Noto Serif SC + Josefin Sans |
| Images | Unsplash CDN (internet connection required) |
| Build | None — open `index.html` directly |

## Getting started

No build step required. Open the file directly in any modern browser:

```bash
# Windows
start index.html

# macOS
open index.html

# Serve locally (avoids CORS issues with background-attachment: fixed)
npx serve .
# or
python -m http.server 8080
```

## Images

All photos are fetched from the Unsplash CDN at runtime — **an internet connection is required**. The hero background is set in `styles.css` under `#hero { background-image: ... }`. Dish images are inline `<img>` tags with `src="https://images.unsplash.com/photo-{id}?w={width}&q=80"`.

## Contact Us & Google Maps

The Contact Us section (`#contact`) embeds a Google Maps iframe using a no-API-key embed URL:

```
https://maps.google.com/maps?q=8+Ann+Siang+Hill+Singapore+069790&output=embed
```

This section was generated by the Anthropic SDK agent in `agent_add_contact.py` (uses `claude-opus-4-8` with tool use to read/write the site files).
